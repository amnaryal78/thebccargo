# DESIGN_SYSTEM (truth = `src/design/tokens.css`, live samples at `/_kit`)
- Brand (2026-10-30): Oxford `--ox-900 #0B2D63` (structure, trust), Gold `--gd-500 #F2B632` (action; one gold action per view). Scales ox/gd/ink, plus rd/gr for status only. Light theme only (no dark mode). Gold as text on light = `--gd-700 #8A6200`. `scripts/contrast-check.ts` reads the same values: 32/32 AA pairs pass.
- Semantic: `--bg` warm ivory canvas, `--surface` white cards/fields, `--surface-2` wells, `--surface-oxford` footer/bands, `--text #16223A` (navy-tinted ink), `--text-muted`, `--line`/`--line-strong`, `--brand`, `--accent`, `--on-accent`, `--focus-ring`, status `--success/-bg --warning/-bg --danger/-bg --info/-bg`, shipment stages `--status-booked|transit|hold|delivered|problem`.
- Type: Archivo (display, `font-heading`), Public Sans (text), JetBrains Mono only for codes (`.code-text`: AWB, tracking, phone). Scale `--fs-display h1 h2 h3 h4 lead body small micro`; `--lh-*`, `--measure 68ch`. Sentence case everywhere: no all-caps labels, no tracked-out eyebrows (old page code still has some; remove as each page is redesigned).
- Space `--sp-1..9` (8-128), `--section-y`, `--control-h 48px`. Layout `--container 1200`, `--container-narrow 760`, `--gutter`; classes `.container-page .container-narrow .section-y .measure`. Breakpoints = Tailwind sm 640 / md 768 / lg 1024 / xl 1280.
- Shape: radius grows with size: `--r-xs 6` badges, `--r-sm 10` buttons/inputs, `--r-md 16` cards, `--r-lg 24` sheets/modals. Depth: border + navy-tinted shadow (`shadow-hard-xs/sm/md/lg`, legacy names). `--z-sticky/overlay/modal/toast`.
- Primitives (`src/design/primitives`, import from the index): Button (primary gold, secondary oxford, outline, ghost, danger; hover deepens the same colour), Input, Select, Textarea (one label/border/focus/error style), Toggle, Chip, Tabs, Accordion, Card, Badge (tones), StatusBadge (+ `stageOf` maps staff free text to a stage; unknown is never red), Container/Section/PageHeader, SectionHeading, Spinner/LoadingState, Skeleton, EmptyState, ErrorState, Modal, BottomSheet, Toast, Stepper, Timeline, Counter. `src/components/ui/` keeps only components with no primitive equivalent.
- States: loading = Skeleton when the shape is known, else LoadingState naming what loads; errors say what happened and what to do (ErrorState), never apologise; empty = EmptyState with one action. Focus: 2px `--focus-ring` ring with offset on every control.
- Rules: tokens or token utilities (`bg-ox-900`, `text-gd-500`, `bg-[var(--surface)]`), never raw hex in components (illustration art in `howtoship/anim`, `services/ServiceIllustration`, `Globe3D` is the exception). Hover only under `(hover:hover)`; touch targets >= 44px; inputs >= 16px on touch.
