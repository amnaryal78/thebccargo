1. DESIGN SYSTEM & VISUAL STYLING
--------------------------------------------------------------------------------
- Translucent Capsule Navbar:
  Implemented a modern floating glassmorphism header (`.navbar-glass`) featuring:
  * `backdrop-filter: blur(12px)`
  * Subtle 1px translucent border highlight (`1px solid var(--border-light)`)
  * Smooth theme-aware background gradients

- Dark Mode Default Theme:
  * Configured default theme to Dark Mode across all HTML pages (`<html lang="en" data-theme="dark">`).
  * Updated JavaScript theme initialization fallback in `js/main.js` to default to `dark` if no prior user choice is saved in `localStorage`.
  * Included a quick-toggle theme button (`#themeToggle`) with dynamic icon switching (sun/moon).

- Micro-Animations & Custom Particle System:
  * Interactive 5% glow custom particle cursor trail on canvas (`js/hero-enhanced.js` & `css/hero-enhanced.css`).
  * RequestAnimationFrame (RAF) scheduled 3D card tilt effect (`.tilt-card`) with smooth spring physics (`cubic-bezier(0.16, 1, 0.3, 1)`).

- Border-Hover Jitter & Flicker Fix:
  * Resolved rapid hover/unhover flickering when mouse hovers near card borders by applying `pointer-events: none !important;` to:
    - Decorative pseudo-elements (`::before`, `::after`)
    - Custom cursor ring and trailing canvas layer
    - Card overlays and tilt glow wrappers

3. BACKEND & DATABASE ARCHITECTURE (`backend/`)
--------------------------------------------------------------------------------
- Node.js & Express API Gateway (`backend/server.js`):
  * Built a Node.js Express server to handle API calls, static file serving, and database management.

- Embedded SQLite Database (`backend/database/db.js` & `cargo_store.db`):
  * Integrated an embedded SQLite database using `sqlite3`.
  * Created tables:
    1. `shipments`: Stores tracking_id, sender_name, sender_phone, receiver_name, receiver_phone, weight, total, status, shipping_date, remark.
    2. `inquiries`: Stores contact form inquiries (full_name, email, phone, service, message).
    3. `articles`: Stores news articles data.
    4. `access_logs`: Logs IP address, origin, referer, path, and HTTP status code for security monitoring.
  * Synchronized exact records from Google Sheet (`BC2204AT`, `BC-21-A-01`, `BC-21-A-02`, `BC210703AR`).

- Strict Origin & Referer Link Security Verification (`verifyAuthorizedOrigin`):
  * Middleware inspects incoming HTTP request headers (`Origin`, `Referer`, and custom `x-bc-gateway-token`).
  * If an unauthorized link, scraping bot, or external site attempts to query the backend or database directly, the request is blocked with HTTP `403 Forbidden`:
    `{"success": false, "error": "Forbidden: Access Denied. Request link or origin is not authorized..."}`.

- Automatic Port Fallback Listener:
  * Listens for `EADDRINUSE` port collision errors. If port 3000 is occupied by another process, `server.js` automatically binds to the next available port (3001, 3002, etc.) without crashing.

- Google Sheets Integration:
  * Environment configuration (`backend/.env`) configured with `SPREADSHEET_ID` and `GOOGLE_SHEETS_API_KEY`.
  * Supports fetching live Google Sheets data with automatic fallback to the SQLite database.
