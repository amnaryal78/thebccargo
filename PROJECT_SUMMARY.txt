4. SECTION RESTORATION & ANIMATION DIAGNOSTICS
--------------------------------------------------------------------------------
- Section Display Fix:
  * Identified root cause of invisible homepage sections (`why-section`, `network-section`, `testimonials-section`, `news-section`).
  * Diagnosis: Elements inside these sections used `data-aos` attributes, which defaults to `opacity: 0` in CSS. The AOS library was missing from `index.html`, leaving elements permanently hidden.
  * Resolution: Integrated AOS CSS and JS library links into `index.html` and added a resilient `IntersectionObserver` fallback in `js/main.js` (`initAOSAndGSAP()`) to guarantee visibility even if external CDNs are slow or offline.

- Global Network Flag Marquee:
  * Restored dynamic country flag list rendering via `initFlags()`.
  * Added CSS `@keyframes flagsMarquee` and `@keyframes flagsMarqueeReverse` in `css/home.css` for smooth infinite horizontal scrolling of flag badges.

- Partners & FAQ Restorations:
  * Restored logistics partners marquee (`initPartners()`) and interactive expandable FAQ accordion (`initFAQ()`).
